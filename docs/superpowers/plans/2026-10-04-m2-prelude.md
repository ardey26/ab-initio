## Global Constraints

- Mass is `u32` and exactly conserved every tick; `conserved_mass()` is debug-asserted in `step_timed`.
- Same seed, same `state_hash` at 1, 4 and 8 threads; `tests/golden.rs` pins history for seed 1234.
- Material identity is the quantized bin; ids never reassigned.
- Code contains no nouns for emergent things.
- Checkpoint format version bumps whenever `World`'s serialized layout changes; `checkpoint::load` rejects old versions.
- Budgets (spec 9): <= 0.4 us per agent-step all phases at 8 threads; >= 6x speedup on 8 threads; measured by `abi-bench throughput` and `abi-bench speedup` at 256x256, pop 9800, 300 ticks, warmup 100, recorded in `docs/perf.md` with the commit hash.
- The emergence canary (`cargo test --release -p abi-bench -- --ignored`) must pass at the end of every task that changes agent behaviour, with its seed list re-selected per its doc comment if seeds flipped.

## Review Focus

1. Task 2 changes what `strike` mines and what memory records; the canary seeds may flip. The task must re-run the 21-seed scan and re-select, never loosen the 50% threshold. Test: canary passes after re-selection.
2. Task 3 `resume` must produce a history identical to an uninterrupted run. Test: run 60 ticks; run 25 ticks then resume to 60; hashes equal; metrics.csv has no duplicate rows.
3. Task 4 parallel sort must produce byte-identical agent order. Test: golden hash unchanged; `sort_agents` old vs new on random worlds give identical `agents` id sequences.
4. Task 4 fused fields must conserve soil and water exactly and match the old three-pass result bit for bit. Test: compare against the retained reference implementation on random grids.
5. Task 6 experiment variants must not leak into default behaviour. Test: default `WorldConfig` hash unchanged by the presence of the variant switches.

```rust
    // Co-location: each living agent records the lowest-id other living agent in its cell.
    let n = ctx.agents.len();
    for la in 0..n {
        if !ctx.agents[la].alive { continue; }
        let (x, y, id) = { let a = &ctx.agents[la]; (a.x, a.y, a.id) };
        let here = ctx.grid.idx(x, y);
        let other = ctx.locals_in(here).find(|&l| l != la && ctx.agents[l].alive && ctx.agents[l].x == x && ctx.agents[l].y == y);

            let oid = ctx.agents[o].id;
            ctx.agents[la].memory.record(oid, [0.0, 0.0, 0.0, 1.0], ctx.tick as u32);
        }
    }
```
